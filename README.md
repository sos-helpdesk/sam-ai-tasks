# Python Mini Projects

This repository contains Python mini projects developed as part of the internship tasks.

## Projects

### 1. Chatbot (chatbox.py)
A simple rule-based chatbot that responds to user input with predefined responses.

### 2. Translation Tool (list.py)
A language translation tool using the deep_translator library to translate text between English, Tamil, Hindi, and other languages.

### 3. Recommendation System (system.py)
A genre-based recommendation system that suggests movies based on user preference (action, comedy, romance, scifi).

### 4. To-Do List Manager (Task4_Todo_List.py)
A command-line to-do list application to add, view, and remove tasks with file storage.

## How to Run
1. Install required package: `pip install deep-translator`
2. Run any file using: `python filename.py`
